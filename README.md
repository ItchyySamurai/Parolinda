# Parolinda

A Ruzzle-style Italian word game, made for Linda. Solo timed rounds, fully
offline once installed, no ads, no accounts, no network calls at any point.

*Parole* + *Linda* — and it reads as *parola linda*, since **lindo/linda** is
Italian for neat, tidy, spotless.

The repo root **is** the site — that's what lets GitHub Pages serve it with a
single dropdown, no build step and no path juggling.

```
index.html  style.css  game.js  dawg.js  dict.bin  manifest.webmanifest  sw.js
icons/      the PWA icons, L monogram drawn procedurally
build/      how dict.bin and the icons were made; not needed to run the game
```

## Making it hers

Two constants at the top of `game.js`:

```js
var PLAYER = 'Linda';
var DEDICA = 'Fatto con affetto per la mamma.';
```

`PLAYER` drives the record label and every line of praise. `DEDICA` is the line
at the bottom of *Come si gioca* — **put your name in it**; it currently doesn't
say who it's from.

The home screen greeting rotates on every visit to the menu and follows the
clock: *Buongiorno* before noon, *Buonasera* after six, plus a general pool
(*Facciamo due parole?*, *Quante ne troviamo oggi?*). Edit `greetingPool()` in
`game.js` to add more. Its adjectives agree with a feminine subject.

Nothing else in the codebase hardcodes a name. The palette lives as CSS
variables at the top of `style.css` — `--accent` is the green, and the
background carries the same hue so the green reads as the room's colour rather
than a highlight on a colder one. Every pair clears WCAG AA. The icon is
regenerated by `python build/make_icons.py`, which keeps its own copy of the
three main colours.

## Putting it on her phone

1. Create an empty GitHub repo (public — Pages needs that on a free account).
2. From this folder:

```bash
git init && git add . && git commit -m "Parolinda" && git branch -M main
```

3. Point it at your repo and push:

```bash
git remote add origin https://github.com/USERNAME/REPO.git && git push -u origin main
```

4. On GitHub: **Settings → Pages → Source: Deploy from a branch → main / (root)**.
   Wait a minute, then the site is at `https://USERNAME.github.io/REPO/`.
5. On her phone, open that link **in Chrome**, then menu **⋮ → Aggiungi a
   schermata Home** (Add to Home screen). Chrome may offer "Installa app"
   instead — either is fine.

That's the only moment she needs internet. The service worker precaches
everything including the dictionary, so from then on it launches from the
home-screen icon and runs with the phone in airplane mode.

Serving it over plain `http://` from a LAN address works for a quick look, but
Chrome will not register a service worker or offer to install outside a secure
context — so the home-screen icon and the offline behaviour only appear once
it's on HTTPS.

To ship a fix later: edit, **bump `CACHE` in `sw.js`**, push. Her copy updates
the next time she opens it while online. If you don't bump `CACHE`, the old
files keep being served and nothing appears to change.

## Sfida del giorno

One board per calendar day, the same for everyone, seeded from the date with
mulberry32 — letters and bonus tiles alike. She can replay it as often as she
likes and only her best score for the day is kept.

It's fixed at **3 minutes** on purpose: a daily board is only worth comparing if
the clock is the same, both against yesterday and against whoever else is
playing it. Two people on separate phones with no connection between them get
identical boards and comparable scores.

Free play is a fresh random board each time and keeps its own record per round
length, separate from the daily.

## The dictionary

`dict.bin` is 2,671,495 Italian word forms in 558 KB.

The source is the LibreOffice/Hunspell `it_IT` dictionary (GPL-3), which stores
**stems plus affix rules** rather than finished words. `build/build_dict.py`
expands those rules into every inflected form — this is the step that decides
whether the game feels right, because shipping the stems raw would reject
almost every conjugated verb and plural.

It then:

- folds accents to base letters, so *città* is found by tracing `CITTA`;
- drops words needing J K W X Y, which are not Italian letters and never appear
  on the board;
- drops capitalised entries (proper nouns, acronyms);
- drops roman numerals — the source lists them lowercase, so `clv` and `mcv`
  would otherwise be playable words. The script prints everything it removes
  this way, so a real word going missing is visible rather than silent;
- sets a **3-letter minimum**. At 2 letters the source's unit symbols (`mq`,
  `cl`, `hg`, `dm`) dominate, and they're farmable by tapping adjacent pairs at
  random. Change `MIN_LEN` in `build/build_dict.py` if you disagree.

The result is packed into a DAWG: a deduplicated prefix graph, one uint32 per
edge, walked directly out of the `ArrayBuffer` so an old tablet never holds
2.6 million JavaScript strings in memory.

To rebuild:

```bash
python build/build_dict.py
```

## Board and scoring

Letter values are the Italian Scrabble table. The **tile distribution is
measured from the dictionary**, counting each letter once per word across words
of 3–8 letters — the lengths a player actually finds. Deriving it from the whole
list instead would shape the board around 16-letter inflections nobody reaches.

Every board is solved before it is handed over, and redrawn unless it holds at
least 80 words, 4 of them 6+ letters, and 5–9 vowels. That costs about 1 ms.
A raw random board is often a dud; this is why Ruzzle boards feel generous.

Word score = (letter values × any letter multiplier) × word multipliers, plus a
length bonus of +5/+10/+15 at 5/6/7 letters and +20 at 8 or more.

## Notes

- Both input styles work: drag across the letters, or tap them one at a time
  and press **✓**. Dragging is not easy for everyone.
- Praise on the results screen reacts to the round — a new record, a long word,
  coming close to her best — rather than firing the same exclamation every time.
- Lifetime stats (games, words found, best word ever) are on the home screen.
- The round pauses automatically if she switches away from the app.
- Sound is synthesised with WebAudio — there are no audio files to ship — and
  can be turned off on the home screen.
- Progress lives in `localStorage` under the `parolinda.` prefix. It survives
  updates, but clearing the browser's site data for that origin wipes it.
